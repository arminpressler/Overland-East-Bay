Cloudflare Worker BFF API Endpoints

Interactive testing harness and OpenAPI documentation available at web_bff_test.html.

  • POST /auth/session — Google OAuth session creation (exchanges Google JWT for 7-day session token & cookie)
  • GET /auth/me — Authenticated member profile & trip agreement signature status check
  • POST /auth/logout — Terminate active session and clear cookies
  • POST /signature — Group Trip Agreement signature submission with Turnstile bot verification
  • GET /rsvp — Fetch trip participant roster from GitHub DB (privacy-preserved: omits emails/phones)
  • POST /rsvp — Submit/update trip RSVP and automatically record trip agreement signature
  • GET /trip — Fetch list of trip directories from the GitHub RSVPs database
