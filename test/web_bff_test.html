1. Google OAuth Session Creation

Exchanges a verified Google OAuth GSI ID token (JWT) for a 7-day session token and HttpOnly cookie.

POST /auth/session

Verifies Google ID Token via Google Remote JWKS, registers user profile under profiles/<cleanEmail>.json in GitHub DB, and stores session in Workers KV.

Google JWT Credential

2. Authenticated Member Profile & Signature Status

Retrieves active user profile and checks GitHub signatures folder for trip agreement signature status.

GET /auth/me

Validates session cookie or Bearer token header against Workers KV and checks signature status (version, timestamp, hash).

3. Logout / Session Termination

Terminates user session and clears session cookies.

POST /auth/logout

Deletes session:<sessionId> from Workers KV and sets Set-Cookie: session=; Max-Age=0.

4. Group Trip Agreement Signature Submission

Captures legal waiver signature with Cloudflare Turnstile bot verification.

POST /signature

Verifies Turnstile token, captures IP/Geo metadata, and commits JSON payload to signatures/<name>-<email>-<date>-<time>.json in GitHub DB.

Full Name
Email Address
Cell Phone
Emergency Contact
Trip ID (Optional)
Turnstile Token

5. Trip Participant Roster (GET /rsvp)

Retrieves confirmed participant roster for a trip with strict email privacy protection.

GET /rsvp?tripId=<tripId>

Parallel fetches all RSVP records from RSVPs/<tripId>/ in GitHub DB. Omits email addresses to protect privacy.

Trip ID

6. Submit Trip RSVP & Signature (POST /rsvp)

Saves member RSVP and automatically commits trip agreement signature record to GitHub database.

POST /rsvp

Commits RSVP status to RSVPs/<trip_id>/<cleanEmail>.json and creates signature record under signatures/.

Trip ID
RSVP Status
Member Name
Member Email

7. Trip Directory List (GET /trip)

Retrieves list of trip directories available in the GitHub RSVPs database folder.

GET /trip

Fetches all trip directories from RSVPs/ folder in GitHub repository database.
